# Akash Bharadwaj — Personal Portfolio

Personal portfolio site for Akash Bharadwaj, Information Systems student at SMU (Business Analytics & FinTech track).

Built with Next.js 16, React 19, Tailwind CSS v4, and Framer Motion. Neo-brutalist design system.

## Stack

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Fonts**: Space Grotesk, Geist Mono (via next/font)
- **Deployment**: Vercel

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Lint
